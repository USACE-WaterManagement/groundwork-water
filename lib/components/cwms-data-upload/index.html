CWMS Data Upload

Instructions

  • STEP 1: Prepare Excel Data
    • Use the provided excel as the template for the data upload (cwms-data-upload.xlsx).
    • "OFFICE" (required) column should contain three characters string.
    • "TSID" (required) column should contain characters string. (Rend Lk-Big Muddy.Stage.Inst.30Minutes.0.cwms-data-upload) (time series id need to existing in CWMS). If tsid not already exists, new tsid will be created
    • "DATE TIME" (required) column should contain date and time values in local time. The format is yyyy-mm-dd hh:mm:ss (ex: 2024-01-01 12:00:00). When loading to CWMS, the date time will be converted to UTC time.
    • "VALUE" (required) column should contain numeric values.
    • "QUALITY CODE" (optional) column should contain numeric values. If not provided, the quality code will default to 0.
    • "DATA ENTRY DATE" (optional) column should contain date and time values in local time. If not provided, the entry date will default to the current date and time.
    • "TEXT TIME SERIES" (optional) column should contain a string. If not provided, the text data will be empty and no payload will be sent to CWMS for the text time series.
  • STEP 2: Load Excel File
    • Click on the "Select File" Button and browse to your excel file.
